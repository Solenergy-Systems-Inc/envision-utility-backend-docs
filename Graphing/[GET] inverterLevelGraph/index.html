    [GET] inverterLevelGraph

    /api/graphing/inverterLevelGraph

    Important Note:

    • This is the replacement for the old GET inverterLevelGraph endpoint
    • This endpoint is meant to be used in conjunction with GET inverterLevelStats.
    • Use the same query string parameters for both endpoints to ensure that the data is consistent.

    InverterLevelGraphRequestDTO

    Bases: BaseModel

    Attributes:

    Name Type Description
    start_datetime datetime

    datetime in ISO format (YYYY-MM-DDTHH:MM:SS+HH:MM)
    end_datetime datetime

    datetime in ISO format (YYYY-MM-DDTHH:MM:SS+HH:MM)
    inverter_station_id str

    ID assigned to the inverter station
    inverter_id Optional(str

    unique device ID assigned to an inverter
    graph_type str

    GraphTypeEnum

    GraphTypeEnum

    Bases: str, Enum

    Attributes:

    Name Type Description
    LINE

    5 minute interval for data if single day and 15 minutes for multiple days
    BAR

    1 hour interval for data if single day and 1-day interval for multiple days

    InverterLevelGraphResponseDTO

    Bases: BaseModel

    Attributes:

    Name Type Description
    data list

    list of lists containing datapoints
    order list

    list of strings containing the order of the data
